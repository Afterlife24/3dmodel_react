# 3D Model Viewer

A modern React application using Three.js to display and animate 3D models.

## Setup

```bash
npm install
npm run dev
```

## Features

- Fullscreen 3D viewer with dark background
- Three animation states: Idle, Wave, Talk
- Smooth animation transitions
- Auto-return to idle after wave/talk animations
- Modern UI with hover effects
- OrbitControls for camera manipulation

## Tech Stack

- React 18
- @react-three/fiber
- @react-three/drei
- Three.js
- Vite
